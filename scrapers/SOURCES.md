# Data sources

Every entry in `public/npr_data.json` carries a `list` id (e.g. `2024songs`, `2022albums`,
`2020listeners`). This manifest maps each `list` id to the NPR source it came from, so any song or
album in the app is traceable back to its origin.

Keep this in sync when you add or change a scraper (the source URLs also live in each
`scrapers/years/*.ts`).

## Legacy album data (2010–2020)

The original nprcore dataset's album lists (`2010`–`2020` + `YYYYlisteners`), sourced from NPR
Music's year-end critics' picks and listeners' polls. Preserved across scrape runs (the `build.ts`
merge keeps any `list` it didn't just re-scrape). Only 2010/2012/2014 are so far reproducible from a
scraper — the rest still live only as committed JSON (see below).
